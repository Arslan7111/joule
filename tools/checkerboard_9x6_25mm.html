Print at 100% / "Actual size" — do NOT use "Fit to page." Landscape, A4. This grid is 10×7 squares (9×6 inner corners), 25mm per square by design — matches tools/calibrate.py's default PATTERN=(9,6) and --square-mm 25.

After printing, measure one square with a ruler before using it. Printer scaling drifts. If it measures something other than 25mm, use the measured value in --square-mm instead of 25 when you run calibrate.py — a wrong square size scales every triangulated distance by the same wrong factor.

Mount the printed sheet on something rigid (cardboard, a clipboard, a laptop lid) so it stays flat. A checkerboard that bows or wrinkles hurts corner detection.
