Correction carried over from candidate 02's review

The "supported movements" list on this screen is deliberately different from PRODUCT_SPEC.md §3.3's own onboarding copy. That copy ("Joule currently tracks: squat, deadlift, curl, row, overhead press") turns out to be the actual source both candidate 02's Stitch screens inherited — and it predates almost all of this project's classifier validation work (spec written 2026-08-07, commit fb9427b; the confidence-gating and lunge-recovery findings that contradict it landed 2026-08-11/12).

This screen uses the current validated state from HANDOVER.md instead: a three-tier disclosure (tracked / early support / not yet) rather than the spec's flat two-tier list, so "developing" claims don't get flattened into either "yes" or "no." PRODUCT_SPEC.md §3.3 itself already anticipates this — §4's Sprint 0 says to "finalize the MVP exercise list against whatever Phase D actually confirms holds up" — this screen is a candidate for that finalized copy, not a deviation from intent.
