01
SPEC §2.1 · FEATURE 1 + 5

Check-in

Binds a fresh Re-ID embedding to the member within 3 seconds of a QR/badge tap. The coverage card is the plain-language limitations disclosure the spec insists on — set on the very first screen, not buried in settings, so no one discovers "sit-ups aren't counted" mid-set.

02
SPEC §3.3 · LIVE SESSION VIEW

Live session

Deliberately not a live form overlay — mid-rep scoring at this fidelity isn't validated yet, so promising it would be the single most damaging overclaim the app could make. Just a glanceable counter and the frame-exit cue, which is engineered to be faster than and independent of the scoring pipeline.

03
SPEC §3.3 · POST-SESSION REPORT

Report

The hero screen. The skeleton overlay — this product's actual output, not an icon — carries the one deviation that matters most, paired against a reference. Never more than two coaching cues, and one always names something done well, not only what to fix.

Confidence language

3D · FUSED

Solid outline — 2+ calibrated cameras agree. Highest-confidence read.

2D · SINGLE

Dashed outline — one camera's estimate. Never shown as equal to a fused read.
